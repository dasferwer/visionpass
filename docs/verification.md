# Проверка VisionPass

Локальная проверка 30 сентября 2026 года выполнялась на PostgreSQL 17 и RabbitMQ 4.

- Ruff и mypy прошли; ошибки типов в 18 модулях приложения не обнаружены.
- Pytest: 16 тестов прошли, включая конкуренцию удаления с медленной обработкой,
  повторную регистрацию, истечение сроков, шифрование и карантин брокера.
- Миграция первоначальной схемы во временной базе сохранила участника и попытку
  доступа, зашифровала старые фото и вектор, очистила открытые поля.
- Полный Compose-стенд запущен: API, БД и RabbitMQ прошли healthcheck, фоновые
  процессы работают. Сквозной HTTP-сценарий завершился успешным доступом и удалением.
  Процесс API использует UID 10001.

Реальный CV-адаптер, качество распознавания, нагрузка и восстановление резервной
копии не проверялись. Демо-адаптер не распознаёт лица.
